# סטודיו לאיפור - יומן עבודה וניהול תורים 💄📅

אפליקציית Flutter מלאה ומשוכללת לניהול יומן עבודה ותורים לאיפור/עיצוב שיער -
כוללת לוח שנה חזותי, ניהול תורים מלא (הוספה/עריכה/מחיקה), סטטיסטיקות הכנסה
חודשית, וגיבוי/שחזור אוטומטי ל-GitHub.

## מה השתנה מהגרסה הקודמת?

בבדיקת הפרויקט המקורי נמצאה הסיבה המרכזית לכשלון ביצירת ה-APK:
**הפרויקט הכיל רק את קוד ה-Dart (`lib/`) וקובץ Kotlin בודד, אך היה חסר לחלוטין
את כל שלד האנדרואיד הנדרש** (`build.gradle`, `AndroidManifest.xml`, גרסת
Gradle Wrapper, אייקונים, ערכות עיצוב וכו'). Flutter פשוט לא יכול לבנות APK
בלי התשתית הזו - וזו הסיבה לשגיאה שקיבלת.

בנוסף, מסך לוח השנה היה שלד ריק בלבד ("תצוגת לוח שנה" כטקסט placeholder) -
בלי לוח שנה אמיתי, בלי הוספת תורים, ובלי חיבור בין הנתונים למסך.

### הגרסה החדשה כוללת:

| תחום | מה נוסף/שופר |
|---|---|
| **שלד אנדרואיד** | נוצר מחדש במלואו: `build.gradle`, `AndroidManifest.xml`, אייקונים, ערכות נושא, Gradle Wrapper |
| **לוח שנה** | לוח שנה אמיתי ואינטראקטיבי (חבילת `table_calendar`) עם תצוגת חודש/שבועיים/שבוע, נקודות סימון לימים עם תורים |
| **ניהול תורים** | מסך הוספה/עריכה מלא: שם, טלפון, תאריך ושעה, משך זמן, קטגוריה, מחיר, הערות, סטטוס |
| **שמירת נתונים** | כל התורים נשמרים במכשיר עצמו (`shared_preferences`) - עובד גם לגמרי אופליין |
| **סטטיסטיקות** | סרגל עליון עם מספר תורים והכנסה חודשית מחושבים אוטומטית |
| **ניהול מצב** | שכבת `Provider` מסודרת (`AppointmentsController`) במקום קוד מפוזר |
| **סנכרון GitHub** | כעת כולל גם **שחזור** (הורדה) בנוסף לגיבוי (העלאה), עם מיזוג חכם של נתונים, ושמירת ההגדרות כך שלא תצטרכו להקליד אותן כל פעם |
| **בנייה אוטומטית** | ⭐ נוסף workflow ל-GitHub Actions שבונה APK אוטומטית בכל פוש - **פותר ישירות את הבעיה שתיארת** |
| **עיצוב** | ערכת נושא מלאה (בורדו/זהב/ורוד פודרה) על כל רכיבי הממשק, כרטיסיות תורים צבעוניות לפי קטגוריה |
| **תאריך עברי** | ⭐ הלוח שנה הראשי מוצג כעת לפי **חודשים עבריים** (למשל "אלול תשפ״ו") במקום חודשים לועזיים, כולל ניווט קדימה/אחורה בין חודשים עבריים ומספור הימים בגימטריה. התאריך הלועזי המקביל עדיין מוצג קטן בכל תא, לנוחות |

## מבנה הפרויקט

```
makeup_calendar/
├── lib/
│   ├── main.dart                       # נקודת כניסה + הגדרת Provider
│   ├── models/appointment.dart         # מודל תור + קטגוריות + סטטוסים
│   ├── services/
│   │   ├── appointments_controller.dart  # ניהול מצב התורים (ChangeNotifier)
│   │   ├── storage_service.dart          # שמירה מקומית (shared_preferences)
│   │   ├── github_sync_service.dart      # גיבוי/שחזור מול GitHub
│   │   └── wifi_service.dart             # חיבור ל-Wi-Fi של הסטודיו
│   ├── screens/
│   │   ├── calendar_screen.dart          # מסך ראשי: לוח שנה עברי + רשימת תורים ליום
│   │   ├── add_edit_appointment_screen.dart  # טופס הוספה/עריכה
│   │   └── settings_screen.dart          # הגדרות סנכרון ו-Wi-Fi
│   ├── widgets/
│   │   ├── appointment_tile.dart         # כרטיסיית תור ברשימה
│   │   └── hebrew_month_grid.dart        # רכיב לוח השנה העברי (חודש/יום)
│   ├── utils/hebrew_date_helper.dart     # המרות תאריך עברי⇄לועזי (מבוסס kosher_dart)
│   └── theme/app_theme.dart              # ערכת הנושא של האפליקציה
├── android/                             # שלד אנדרואיד מלא (חדש!)
├── .github/workflows/build-apk.yml      # בנייה אוטומטית ב-GitHub Actions
└── pubspec.yaml                         # תלויות מעודכנות
```

## איך בונים APK - שתי דרכים

### 🌟 דרך א' (מומלצת): בנייה אוטומטית ב-GitHub, בלי להתקין כלום

1. צרו ריפוזיטורי חדש ב-GitHub והעלו אליו את כל תוכן התיקייה הזו.
2. עברו לטאב **Actions** ברפו → תראו ריצה אוטומטית של "Build APK" (או הריצו
   ידנית עם "Run workflow").
3. בסיום הריצה (כ-3-5 דקות), היכנסו לריצה שהסתיימה → גללו למטה ל-**Artifacts**
   → הורידו את `makeup-calendar-apk` (קובץ zip שמכיל את ה-APK).
4. העבירו את קובץ ה-APK לטלפון אנדרואיד והתקינו (יש לאשר "התקנה ממקורות
   לא ידועים" בהגדרות המכשיר).

בדרך זו **אתם לא צריכים להתקין Android Studio, Flutter, או Java במחשב שלכם בכלל.**

### דרך ב': בנייה מקומית (Android Studio / VS Code)

1. ודאו שמותקן Flutter (`flutter doctor` אמור לעבור ללא שגיאות קריטיות).
2. מתוך תיקיית הפרויקט, הריצו:
   ```
   flutter pub get
   flutter build apk --release
   ```
3. אם מופיעה שגיאת Gradle הקשורה ל-`gradle-wrapper.jar` (קובץ בינארי קטן שלא
   כלול כאן), הריצו פעם אחת בלבד `flutter create .` בתיקיית השורש - זה ישלים
   אוטומטית קבצי שלד חסרים תוך שמירה על כל הקוד שלכם, ואז הריצו שוב את הפקודות
   שלמעלה.
4. קובץ ה-APK הסופי יימצא ב-`build/app/outputs/flutter-apk/app-release.apk`.

## הערות אבטחה חשובות

- **טוקן GitHub**: השתמשו בריפו **פרטי (Private)** ובטוקן עם הרשאת `repo`
  בלבד. הטוקן נשמר במכשיר עצמו (לא מוצפן) - מומלץ לא לשתף את המכשיר עם
  אחרים, ולשקול שדרוג עתידי ל-`flutter_secure_storage`.
- **סיסמת Wi-Fi**: נשמרת רק בזיכרון הזמני של המסך ולא נכתבת לאחסון.
- **אייקון האפליקציה**: נוצר אוטומטית כפלייסהולדר בצבעי הסטודיו. מומלץ
  להחליף בלוגו אמיתי - ניתן להשתמש בכלי כמו
  [App Icon Generator](https://www.appicon.co/) ולהחליף את קבצי ה-PNG
  תחת `android/app/src/main/res/mipmap-*/`.

## שינוי שם החבילה (Application ID)

מזהה האפליקציה כרגע `com.mua.studiocalendar`. אם תרצו לשנות אותו (למשל לפני
פרסום בחנות Play), יש לעדכן בשלושה מקומות: `applicationId` ב-
`android/app/build.gradle`, את השורה `package` ב-`MainActivity.kt`, ואת נתיב
התיקייה שבה הוא נמצא (`android/app/src/main/kotlin/...`).
